# 本轮实现与结果审查

范围：P3 BitNet I2 扩展、P4 I1 独立验收、P5 定向文献核对及 P6 单项优化。此文件是同一执行者的代码/证据自审，不冒充独立外部评审。

## 审查后落实的修正

1. **跨批量生成断言过强。** 首次 BitNet 测试因不同 B/序列的 token 不同而停止。保留失败记录，逐层检查浮点输入与实际量化后的 INT64 参考，确认本次抽查的整数点积一致；把跨批量一致性改为显式观测，同配置 normal/profile 一致性继续硬性检查。详见 BITNET_NUMERICAL_AUDIT.md，不能据此声称完整质量通过。
2. **I1 图元数据与内核尾部必须分别测。** K=4 图原来直接断言，导致后续测试未运行；现在隔离子进程，并独立测试 row stride，完整 225 项集合保留原版和修复版对照。
3. **I1 分区偏移和累加安全不能靠随机输入。** 根据框架 floor 分区计算 row_start；K=160 是 20 对齐且任意符号前缀均安全的段长。零索引与混合尾部另外覆盖，不能只跑 BitNet 的 20 对齐 K。
4. **优化不修改共享宏。** 仅 I2_V_4 四处调用切到条件宏，I1 保留原路径；默认 OFF，P1/P2/P3 入口明确写 OFF，避免复用 CMakeCache 时意外启用实验。
5. **性能构建口径。** 第一轮 P6 预检使用 RelWithDebInfo，审查后在正式计时前停止；与既有性能实验统一 Release，保留停止原因和日志，没有混用两种编译等级结果。
6. **结果归档和运行入口。** 文本日志统一 LF 后重新记录文件哈希；不上传 GGUF、可执行文件、原始 logits 二进制或凭据。P3/P4/P6 各自保留结果目录与一键入口，不覆盖历史结果。
7. **采样时间上限。** P6 沿用 P2 的 4096 次迭代上限，小边界实际每样本约 0.19 秒；报告明确区分目标 1 秒与实际时间，保留样本但不将该组用于宣称小收益。

## 已核验的边界

- 正确性基线保留 P1 修复；作者固定提交/worktree 未改写。原版错误结果没有作为优化速度对照。
- I1 普通、profile、Sanitizer 均有 225 项与独立 K=4/非法形状检查；I2 164 项、大工作区和非法输入回归通过。
- I2/I1 计数器分开，BitNet 每前向 182 矩阵×4 线程=728 次入口；模型 inventory 与实际调用证据同时存在。
- I1/I2 GGUF 的 288 个其他张量逐字节比较，三值权重抽样 26,045,440 项；没有将抽样标成全量证明。
- Prefill/Decode 的模型加载、共享前缀、固定生成长度、宿主 greedy 扫描及批量吞吐分母已明确。P4 六组与 P3 十八组的范围差异已写入路线。
- 相关工作只声称实际完成的定向阅读/筛选；分块转置不被包装成新算法。
- Python/shell/PowerShell 语法、报告本地链接和 674 份本轮发布证据的 SHA256 检查通过；暂存范围和凭据模式检查通过。Git whitespace 检查通过，原始日志/patch/CMakeCache 保留生成器空白，不改写证据；作者 worktree 保持干净。

## 尚未覆盖

标准质量/困惑度、长上下文、其他 I1/I2 变体、ARM/AVX512、服务器、硬件 cache miss/能耗计数、跨日重复实验均未执行。WSL 虚拟 CPU 亲和性不等于已证实的 P/E 核映射。P6 的最终效果与范围以 P6_REPORT.md 为准，不从局部阶段改善外推模型加速。

P6 的两模型 OFF/ON 确认已完成（120 样本、对应生成 token 一致）。模型/线程相关的收益和退化都保留；BitNet 单线程收益幅度跨批次不同，Falcon 四线程 Decode 两批退化。自审结论为保留默认 OFF 的实验入口，不批准普遍默认启用。

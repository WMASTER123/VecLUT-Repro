# BitNet 3B 跨批量生成差异审查

2026-11-17，固定 I2_V_4 模型。此记录解释 P3 功能检查中出现的真实差异，不能替代标准质量评测。

## 观察与判定

第一次完整 P3 扩展在新增的跨序列 token 一致性断言处停止：`p3-20261117-223614-411`。B=1、B=4 的 normal/profile 各自 token IDs 完全一致，但 B=4 不同序列、B=1 与 B=4 的续写不完全一致。失败日志保留；该次没有正式性能结果。

随后对真实计算图增加只在显式环境变量启用的节点回调，以及独立 INT64 抽样参考。相同输入的四序列在第一个 Decode 前向的注意力输出 `kqv_out-0` 首先出现约 `1.90735e-6` 的浮点差异；此时最终四路 logits 相同。

第二个 Decode 前向中，首个量化整数分歧出现在第 16 层（0-based layer 15）：

| 节点 | 输入最大序列间差异 | 量化后相对 lane0 不同的元素数（合计） | 输出最大差异 | 抽样 INT64 参考误差 |
|---|---:|---:|---:|---:|
| ffn_gate-15 | 1.788139e-7 | 2 | 0.008544922 | 0 |
| ffn_up-15 | 1.788139e-7 | 2 | 0.008544922 | 0 |
| node_686，后续 down | 0.000648975 | 26 | 0.175163746 | 0 |

该前向的 **182 个 I2_V_4 矩阵**均检查每序列的 3 个输出坐标，按原始打包字节独立解三进制、按相同 INT8 激活计算 INT64 点积，所有抽样误差为 0。最终 logits 序列间最大绝对差达到 `0.249548912`。完整节点摘要和 logits 比较保留在 `results/p3-bitnet-probe/`。

证据支持：普通浮点计算顺序带来的微差跨过量化舍入阈值，随后被网络放大。不能由不同生成文本直接判定 LUT 整数计算错误；也不能由抽样误差为零宣称整个模型与浮点模型无损。量化阈值处的不连续性是数值敏感性，不为让文本一致而偷偷改变量化规则或替换模型。

## 验收调整

保留有限 logits、非空生成、固定配置 normal/profile token 一致、实际内核计数和独立小矩阵正确性作为检查。跨 B、跨 lane 的 token 一致性改为**显式报告的观察值**，不再假定所有模型必须逐 token 相同。Falcon3 的既有一致结果保留，但不外推。

这项调整只改变不恰当的文本一致性验收项，没有放宽整数内核参考误差，也没有修改模型执行算子。性能仍只在无诊断环境下测量；runner 拒绝继承任何 `P3_AUDIT_*` 环境变量。

## 复查方式

`bench-p3` 的 `P3_AUDIT_LOGITS=<E盘前缀>` 输出二进制 logits，`P3_AUDIT_NODES=<E盘jsonl>` 输出节点摘要，`P3_AUDIT_STEP=1` 指定第二个 Decode 前向。仅 `smoke` 使用 logits 导出，节点审查只选正式重复的指定步。`analyze_logits.py` 对 B1/B4 的前四步输出进行比较。

这些诊断改变执行/计时开销，**不能把其耗时写入性能表**。现有记录是单提示、少量步数和抽样坐标的调查，不是困惑度、任务准确率、长生成稳定性或全坐标模型质量证明。

# P6.5：连续 INT32 复核与尾块有效 lane 实验

2026-11-18。本轮结束；没有后台测试待跑。原样复核和阶段诊断完成；新尾块候选未通过门槛，已从当前分支删除实现、CMake选项和专用构建/性能脚本。旧连续INT32候选按用户要求保留、默认OFF，不合并稳定版。

## 结论先行

- 旧连续INT32：本轮268个模型样本，7/8主Prefill配置的点估计快≥5%，但Decode守护及波动条件未通过。此前P6.4通过不等于这次复核通过。3个配置复测后CV仍>10%；不能把其中的较大加速或退化认定为稳定效果。
- 新尾块候选：168配置、两批正反序，含追加守护共4020样本；120个目标配置中只有10个两批均快≥10%，要求>60；57个目标两批均慢>5%。完整块守护复核有17个未通过。停止，不做新候选整模型测试，不按N或模型加特例。
- 整数正确性与ASan/UBSan通过，但不能抵消性能退化。删除的是本轮有效lane生产实现，保留1612项通用边界检查、Git历史和原始证据。

## 3. 本轮只改变什么

原型提交c5c8a53e：I2_V_4最后一个不满32的token tile中，把建表add/rev与查表累加循环的有效lane上限设成N%32。保留作者80步拓扑建表顺序、81表项、物理stride32；完整tile代码原样，K240、INT32连续布局、清零、分配容量、打包、量化均不变。新开关默认OFF，约束T32+safe240+deferred。

N1尾部原来计算32个lane，现在只计算1个；N33前32个仍走原完整块，仅最后1个走新尾块。N31则保留31个计算但引入动态边界。每表项仍占32×INT16=64字节，因此少读元素不代表按相同比例少取缓存行；不声称带宽减少32倍。

## 4. 正确性与损害检查

- Release和ASan/UBSan各通过原P1 164项、P4 225项及既有非法形状/大工作区检查；新增累加边界216项、尾部1612项均无失败。1612项也在未修改deferred二进制上通过。
- 全部尾数1..31，N=rem及32+rem；K16/240/256/496，81种索引、6种激活/权重模式；线程1/4、两slice，独立INT64参考精确相等。padding主动填非零值，防止依赖无效区域恰好为零。
- g4 LUT绝对值≤512，K240子和≤30720，INT16不溢出；INT32总和的既有K限制不变。没有改量化或近似计算。
- 静态审查确认80步依赖相同且每一表行恰好定义一次，I2_V_4完整块/分配部分文本相同。文本相同仍可能因编译代码布局而性能改变，所以必须有完整块守护。
- 没有新权重副本或长期缓存，缓冲区容量不变。RSS是进程级峰值，包含图/线程/库等，不能用于断言内核每次分配字节数。没有用持续换页换性能。
- 新建空构建目录时make出现WSL/NTFS时间戳偏移警告，日志保留；所有目标编译/链接成功且数值与sanitizer通过。计时使用单调钟，不以文件时间推算耗时。没有让构建与性能测试并发。

不因N1偶有收益就添加“仅N1启用”特例。目标退化在两批重复出现，已经足够否决这一具体实现；不是声称所有减少尾部无效计算的方法都不可行。原实现固定32易于编译器向量化；新动态边界会引入循环控制、向量主循环/余数处理，接近满块时省下的算术很少。这是与源码及反汇编相符的解释，未用硬件计数分离各项因果贡献，不把某一种cache miss当作已测事实。

反汇编进一步显示：原固定宽度建表函数为2583字节（约2.5KiB），新动态建表为47147字节（约46.0KiB），约18.3倍。80步拓扑中的动态循环产生额外向量/标量余数路径。比如M=K=2048、N31、单线程，两批加速比为0.356/0.359x，即延迟约为对照的2.8倍。这是实际损害，不能用少数N1收益抵消；代码体积增加是否具体造成指令缓存瓶颈仍未测量。

完整块守护的17个未通过项不能都称为稳定退化：33个触发确认的配置中，7个点估计仍慢>3%，15个CV>10%，两者重叠5个。门槛按预注册规则保守判失败；目标尾块的57个重复退化已足以停止。进程RSS峰值对照/候选分别136084/136252KiB，不能把这个进程级差值当作内核额外分配；源码分配公式保持相同。

## 6. 保留、删除及下一步

保留旧连续INT32候选原样、默认OFF；作者和稳定worktree不动。删除新有效lane头文件、core接入、CMake选项和build/screen/model专用脚本，历史提交可查；新增边界测试仍适用于保留版。没有新候选真实模型加速结论，不启动未过门的模型阶段，也没有做其他框架对比。

下一步不继续扫N阈值救这版原型。当前工程结论是：完整块连续提升值得保留候选，Decode不适合直接推广；尾块确有无效算术，但本轮直接缩短循环方案没有净收益。未来方案必须另立假设和停止门槛，不能把本次失败改写为成功。

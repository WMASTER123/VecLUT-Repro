# P6.3 安全累加段实验：预先确定的方案

2026-11-18。基线提交79db4941。实验分支exp/safe-accum-20261118，独立worktree src，构建/日志在本目录，模型仅链接已有E盘文件。主worktree与默认repro/cpu不修改、不合并；用户可随时回到原入口。失败分支保留证据，不删除原数据。

## 假设与文献边界

原正确性修复每128个K项提升，安全但保守。先用固定240（16对齐、240*128=30720）作更强对照，再验证依据实际INT8激活绝对值和确定提升边界。保持三值权重、量化结果、INT16/INT32语义与最终scale。

Vec-LUT v2 §3.4已有分级累加及离线段长，A2Q+/AXE已有累加界限与模型量化约束；本实验不声称首次安全累加或已确认新颖性。候选区别是无需改权重的运行时安全分段。相关材料沿用本轮已读的 https://arxiv.org/html/2512.06443v2 、https://proceedings.mlr.press/v235/colbert24a.html 、https://arxiv.org/html/2409.17092v1 (§3.3)。

## 最小实现与证明要求

固定240只作基线增强。自适应按16个K项（四张g4表）为原子块，先算各token lane绝对值和。若已有段界限+下一原子块会大于32767，先将旧段提升并清零，再处理原子块；最后强制提升。所有token lane（含padding）都纳入界限，不能依赖抵消。abs前转int，正确覆盖-128。每个原子块界限≤2048；任意部分和均受绝对值和约束。INT32总K限制保留。第一版每工作线程独立算界限，计入其成本，不修改图工作区协议。

三构建：legacy128、safe240、adaptive。三者保持相同选择性分块设置ON，比较相同版本中已知较强方案。新增选项默认legacy128，仅实验分支拥有该选项。I1路径不改。不同时实施延迟转置或清零融合。

## 验收与决策

1. 全量I2/I1回归，加K224/240/256/464/480/496/3200，N1/31/32/33/65，正负极值/零/混合，独立INT64参考；新增图1/4线程、多个slice。候选ASan/UBSan通过后才能计时。
2. 图级六种模型M/K，N32/128，1/4线程，两个相反顺序批次，每版本5样本，目标150ms，作为筛查，非长采样最终结论。
3. 若adaptive相对safe240没有多数正常Prefill形状>5%的正向证据或频繁>5%退化，停止扩大，不靠只挑单线程一个形状宣传。若通过，真实两模型P32/128/256、1/4线程用固定CPU与逐样本ABBA/BAAB验证，各版本至少6样本。先测P128两个模型/两线程配置，失败则不扩展。
4. 固定240即使胜出也只称基线增强，不把相对K128的全部收益称自适应贡献。主要对照adaptive/safe240；保存safe240/legacy128以解释收益来源。模型hash/对应token一致、无swap/major faults，计入界限计算和分派成本。
5. 目标是普通形状/至少两模型的实际收益，不承诺百分比。若仅特定模型受益，保留为受限候选；不合并主分支。独立会话、不同提示/平台推广仍是后续验收。
